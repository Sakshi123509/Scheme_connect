# 🇮🇳 SchemeConnect — Government Schemes Portal

A unified platform to discover and apply for central & state government schemes based on your eligibility.

🔗 **Live Demo:** [scheme-connect-one.vercel.app](https://scheme-connect-one.vercel.app)
🔗 **Backend API:** [scheme-connect-w48p.onrender.com](https://scheme-connect-w48p.onrender.com)

---

## ✨ Features

- 🔍 Browse 100+ government schemes
- 👤 User registration & login
- 📋 Create personal profile
- ✅ Apply for eligible schemes
- 🛡️ Admin panel for scheme management
- 📱 Mobile responsive design

---

## 🛠️ Tech Stack

| Frontend | Backend | Database |
|----------|---------|----------|
| React.js | Node.js | MongoDB Atlas |
| Tailwind CSS | Express.js | Mongoose |
| Vercel | Render | JWT Auth |

---

## 🚀 Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

### Environment Variables

**Backend `.env`:**
```
MONGO_URI=your_mongodb_atlas_uri
JWT_SECRET=your_jwt_secret
PORT=3000
CLIENT_URL=http://localhost:5173
```
